#### 2. Clean Up Stuck Sessions (The "Garbage Collector")

* **The Problem:** Users get "soft-locked" if they abandon a workflow.
* **The Fix:** Add a check in `get_user_session` (Day 26 Task) to auto-delete sessions older than 15 minutes.

```python
# In src/bot/session_manager.py
from datetime import datetime, timedelta

def get_user_session(user_id):
    session = SessionLocal()
    try:
        active = session.query(ActiveSession).filter(ActiveSession.user_id == str(user_id)).first()
        
        # TIMEOUT CHECK
        if active:
            # Assuming you have a last_updated column from Day 23 schema
            # If not, rely on Member A adding it, or skip strict timeout for MVP
            time_diff = datetime.utcnow() - active.last_updated.replace(tzinfo=None)
            if time_diff > timedelta(minutes=15):
                print(f"🧹 Session timed out for {user_id}")
                session.delete(active)
                session.commit()
                return None
        
        return active
    finally:
        session.close()

```
