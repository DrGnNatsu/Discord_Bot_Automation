## Expected Input and Output

### High-Level Overview

- **Input:** The "Parse Tree" (a complex object created by ANTLR that represents the grammar rules).
- **Output:** A clean JSON Object (Instruction Set) that will be saved into the database.

---

### Specific Input & Output for Each Method

Here is exactly what goes **IN** and what must come **OUT** of the key functions in `src/compiler/compiler.py`.

#### A. Method: `visitWorkflow_def`

- **The Input (`ctx`):** `GuildFlowParser.Workflow_defContext` (e.g. `WORKFLOW welcome ON MEMBER_JOIN { ... }`).
- Use `ctx.IDENTIFIER().getText()` (or grammar-specific token) and `ctx.event_type()` to extract name and trigger.

- **The Expected Output:** A dictionary matching `WorkflowSchema.model_dump()` produced by the visitor.

```python
# Expected Output (Return Value)
{
    "type": "WORKFLOW",
    "name": "welcome",
    "trigger": "MEMBER_JOIN",
    "condition": None,   # or a condition dict when WHERE exists
    "steps": [           # a list of statement dicts (actions, if-blocks, sets, etc.)
        { "type": "ACTION", "command": "BAN_USER", "params": {} }
    ]
}
```

#### B. Method: `visitAction_command`

- **The Input (`ctx`):** An object of type `GuildFlowParser.Action_commandContext`.
- This object represents: `SEND_MESSAGE channel=logs content="Hello"`
- It gives you access to the tokens: `SEND_MESSAGE`, `channel`, `logs`, etc.

- **The Expected Output:** A standardized action dictionary.

```python
# Expected Output (Return Value)
{
    "type": "ACTION",
    "command": "SEND_MESSAGE",
    "params": {
        "channel": "logs",
        "content": "Hello"
    }
}

```

#### C. Method: `visitIf_statement`

- **The Input (`ctx`):** An object of type `GuildFlowParser.If_statementContext`.
- This object represents: `IF user.strikes > 3 { ... } ELSE { ... }`
- **The Expected Output:** A logic dictionary containing nested actions.

```python
# Expected Output (Return Value)
{
    "type": "LOGIC_IF",
    "condition": {
        "left": "user.strikes",
        "operator": ">",
        "right": "3"
    },
    "then": [ ... list of actions to run if true ... ],
    "else": [ ... list of actions to run if false ... ]
}

```
