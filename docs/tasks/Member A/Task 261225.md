## 💻 Input & Output Structure (Frontend <-> Backend)

Since this is an integration task, understanding the exact data shape is critical.

### 1. The Request (Frontend Input)

When the Admin clicks "Deploy", your React code must construct and send this **Type-Strict JSON**:

```typescript
// Interface matching the Pydantic model from Dec 24
interface DeployRequest {
  workflow_name: string;   // e.g. "anti_spam"
  admin_id: string;        // e.g. "admin_1"
  script_content: string;  // The raw text from Monaco
}

// Example Data
{
  "workflow_name": "anti_spam",
  "admin_id": "user_123",
  "script_content": "WORKFLOW anti_spam ON message { ACTION: BAN_USER }"
}

```

### 2. The Success Response (Backend Output)

If compilation works, show a Green Toast notification.

```json
{
  "status": "success",
  "message": "Deployment Successful",
  "data": { ...compiled_json... }
}

```

### 3. The Error Response (Backend Output)

If Member A's compiler (Dec 25) finds a syntax error, the API returns this. **You need this structure to draw the red lines.**

```json
{
  "detail": {
    "error": "Syntax Error",
    "message": "mismatched input 'BTN' expecting 'ACTION'",
    "line": 2,       // <--- Critical for Monaco
    "column": 15     // <--- Critical for Monaco
  }
}

```

## 💻 Solution Snippet: The React Component

Here is the logic to connect the Editor to your API and handle the error markers.

```jsx
import React, { useState, useRef } from 'react';
import Editor from '@monaco-editor/react';
import axios from 'axios';

const WorkflowEditor = () => {
  const editorRef = useRef(null);
  const monacoRef = useRef(null); // To access setModelMarkers
  const [status, setStatus] = useState("idle");

  // 1. Setup Editor
  function handleEditorDidMount(editor, monaco) {
    editorRef.current = editor;
    monacoRef.current = monaco;
  }

  // 2. The Deploy Logic
  async function handleDeploy() {
    setStatus("loading");
    const script = editorRef.current.getValue();
    
    // Clear previous errors
    const model = editorRef.current.getModel();
    monacoRef.current.editor.setModelMarkers(model, "owner", []);

    try {
      const payload = {
        workflow_name: "my_workflow", // You can make this dynamic input
        admin_id: "admin_1",
        script_content: script
      };

      // Call the API you built on Dec 24
      const res = await axios.post("http://localhost:8000/api/deploy", payload);
      
      setStatus("success");
      alert(`✅ Success: ${res.data.message}`);

    } catch (err) {
      setStatus("error");
      
      // 3. Visual Error Handling
      if (err.response && err.response.data.detail) {
        const errorData = err.response.data.detail;
        
        // Draw Red Squiggly Line in Editor
        monacoRef.current.editor.setModelMarkers(model, "owner", [
          {
            startLineNumber: errorData.line,
            startColumn: errorData.column,
            endLineNumber: errorData.line,
            endColumn: errorData.column + 5, // Highlight a few chars
            message: errorData.message,
            severity: monacoRef.current.MarkerSeverity.Error,
          },
        ]);
        
        alert(`❌ Error at line ${errorData.line}: ${errorData.message}`);
      }
    }
  }

  return (
    <div>
      <div style={{ marginBottom: "10px" }}>
        <button onClick={handleDeploy} disabled={status === "loading"}>
          {status === "loading" ? "Deploying..." : "Deploy Workflow"}
        </button>
      </div>
      
      <Editor
        height="60vh"
        defaultLanguage="java" // Java highlighting looks similar to your DSL
        defaultValue="// Type your GuildFlow script here..."
        onMount={handleEditorDidMount}
        theme="vs-dark"
      />
    </div>
  );
};

export default WorkflowEditor;

```
